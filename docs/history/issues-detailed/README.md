# Detailed issues (historical)

The 40-issue backlog as it stood before consolidation on 2026-09-23, preserved unchanged. These files are **not** the work queue; `docs/issues/README.md` is. Each milestone issue names the detailed issues it absorbs, and agents read them for scope detail, implementation notes and acceptance detail.

Where a detailed issue conflicts with its milestone on dependencies, "manual verification", "definition of done" or what to record, the milestone and the verification scope in `docs/issues/README.md` win. Specification documents still cite these numbers; the mapping is in `docs/issues/README.md`.
