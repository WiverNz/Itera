# Implementation roadmap

## Phase 0 - Documentation and decisions

Before coding:

- finalize architecture
- finalize domain model
- finalize persistence schema
- define navigation graph
- define exercise state machine
- define training engine rules
- define review scheduling
- define design system
- refine issue backlog

Exit condition:
Another developer or agent should be able to implement issue 001 without inventing major product decisions.

## Phase 1 - App foundation

Issues:
- 001 project bootstrap
- 002 architecture foundation
- 003 design system
- 004 domain model
- 005 persistence
- 006 technique catalog

Exit condition:
The app builds, local data can be stored, and the catalog is available.
