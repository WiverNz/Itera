# Definition of done

An implementation issue is complete only when:

- acceptance criteria are satisfied
- code follows documented architecture
- relevant unit tests are added
- relevant UI tests are added
- user-facing strings are externalized
- accessibility semantics are considered
- dark theme is verified where applicable
- loading/error/empty states are handled where applicable
- persistence behavior is verified
- no known crash exists in the target flow
- documentation is updated when implementation changed a documented decision
- manual verification steps have been executed
