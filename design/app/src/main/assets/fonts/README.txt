Put the brand fonts here (static TTF files from Google Fonts):

  BricolageGrotesque-Medium.ttf
  BricolageGrotesque-SemiBold.ttf
  BricolageGrotesque-Bold.ttf
  InstrumentSans-Regular.ttf
  InstrumentSans-Medium.ttf
  InstrumentSans-SemiBold.ttf
  InstrumentSans-Bold.ttf

Files that are missing are simply skipped and the system font is used instead.
Both families are Latin-only; Cyrillic automatically falls back to the system font.
